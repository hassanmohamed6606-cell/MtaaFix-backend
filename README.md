# MtaaFix – Community Issue Reporting and Tracking System

**Tagline:** Report it. Track it. Fix it.

## 1. Project Overview

MtaaFix is a web-based community issue reporting and tracking system designed to help residents report problems affecting their neighbourhoods.

The application provides a central platform where residents can submit reports, identify problem locations and monitor the progress of reported issues.

## 2. Problem Statement

Community members frequently experience problems such as damaged roads, broken streetlights, uncollected garbage and blocked drainage systems.

However, reporting these issues and tracking whether they have been addressed can be difficult.

MtaaFix aims to simplify this process by providing an accessible digital reporting platform.

## 3. Target Users

- Residents who want to report problems in their communities.
- Community administrators who monitor reported issues.
- Maintenance teams responsible for resolving reported problems.

## 4. Proposed Solution

MtaaFix will provide a user-friendly web application that allows residents to submit community issue reports, search for locations and view existing reports.

The system will also provide report status information to help users track the progress of reported problems.

## 5. Core Features

1. **Dashboard:** Displays report statistics and recently submitted issues.
2. **Report Submission:** Allows residents to submit problem descriptions and select categories.
3. **Location Search:** Uses the OpenStreetMap Nominatim API to search for problem locations.
4. **Community Reports:** Displays submitted reports.
5. **Report Filtering:** Allows users to filter reports by category and status.

## 6. Main Data Resources

- Phase 2: Flask backend and database integration.
- Phase 3: Authentication and authorization.

Each phase will be completed, tested, documented and submitted separately.
